# KADR | كادر

الإصدار: **v1.1**

منصة شخصية لتقييم الأفلام والمسلسلات ومشاركة الذائقة السينمائية.

## v1.1
- إصلاح شاشة تفاصيل الأعمال بدون بوستر على الهاتف.
- دعم التقييم النهائي فقط، مع جعل التقييمات التفصيلية اختيارية بالكامل.
- إضافة تقييم نهائي مستقل لكل مشاهدة/إعادة مشاهدة.
- تحديثات محمية: Candidate على GitHub → تحقق Supabase → اختبار المدير → اعتماد المدير → رفع النسخة إلى الجذر → تحقق ثانٍ → إشعار المستخدمين.
- إشعارات داخلية عبر Realtime وخارجية عبر Web Push.

## النشر الآمن للتحديثات المستقبلية
1. ارفع نسخة التحديث داخل `candidate/` فقط.
2. من لوحة المدير اختر تهيئة التحديث؛ Supabase يرفض التهيئة إذا لم يجد الملفات ورقم الإصدار في GitHub.
3. افتح النسخة التجريبية واختبرها ثم اعتمدها.
4. بعد الاعتماد فقط، ارفع نفس ملفات النسخة إلى جذر المستودع.
5. اضغط «تحقق من GitHub وانشر». عند نجاح التحقق يتغير الإصدار المستقر وتُرسل إشعارات المستخدمين.
